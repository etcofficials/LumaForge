# V0.4 overhaul — repository audit and feature map

Audit of the V0.3 tree (commit `faa6467`, 68 tests green) against the V0.4 master specification.
Legend: **Have** = works today and is kept · **Partial** = foundation exists, needs extension ·
**Missing** = to build. "Plan" names the existing seam each feature extends.

## Architecture that stays

| System | Where | Verdict |
|---|---|---|
| Time (flicks), Rational, Result/Error, Log | `core/` | Have — unchanged |
| Command + UndoStack (merge ids, macros, clean index) | `commands/` | Have — one history for everything new (markers, transitions, keyframes, bins, tracks) |
| Document + Change listeners | `project/Document` | Have — new `Change` kinds for markers/bins |
| Pure edit ops -> `SequenceEdit` -> `SequenceEditCommand` | `project/TimelineOps`, `TimelineCommands` | Partial — edit gains tracks add/remove/reorder, transitions, markers, in/out |
| Project format v2 (.lfproj JSON, lenient reader, atomic save) | `project/ProjectSerializer` | Partial — v3 adds keyframes, transitions, markers, masks, bins, proxies, subtitles; v1/v2 keep loading |
| D3D11 device, WARP fallback, decoder profile + encoder probes | `hardware/` | Have — encoder probe result reused by export (no repeated NVENC opens) |
| Decoders (D3D11VA / software), audio decoder, waveform, thumbnailer | `media/` | Have — export/proxy add encoders + muxer (new `export/` module) |
| Compositor (layers -> render target, YUV->RGB, colour, looks, flips, crop) + readback | `rendering/` | Partial — ordered per-pixel effect stack, masks, transitions, adjustment layers, solid layers, overlays (safe areas/grid), checkerboard |
| Text rasteriser (DirectWrite/Direct2D -> cached BGRA) | `rendering/TextRasterizer` | Have — reused by titles, subtitles, export |
| Playback engine (render thread, per-clip readers, LRU text cache, retry polling) | `playback/` | Partial — shuttle rates (J/K/L, reverse), loop, in/out, snapshot, scope readback, proxy paths |
| SequenceProgram (immutable snapshot per edit) | `playback/SequenceProgram` | Partial — evaluates keyframes, transitions, adjustment clips, pan, audio FX; shared by preview **and export** |
| AudioMixer (gain, fades, speed resampling) | `playback/AudioMixer` | Partial — pan, track/master gain, clip audio effects, meters; reused offline by export |
| WASAPI output | `audio/AudioOutput` | Have — recorder added beside it |
| ActionRegistry (single action table) | `ui/ActionRegistry` | Partial — multi-shortcut, user overrides, categories, palette/editor data source |
| Timeline view (hand painted, regional repaints) | `ui/timeline` | Partial — vertical scroll, track heights, keyframe lanes, transitions, markers, in/out, new tools |
| Inspector (sections + InspectorContext merge ids) | `ui/panels/InspectorPanel`, `ui/inspector` | Partial — tabs, multi-select, keyframe buttons, new sections |
| Media bin (grid/list, search, sort, relink, async thumbnails) | `ui/panels/MediaPanel` | Partial — bins, filters, metadata, proxies, favourites/tags |
| Deployment (windeployqt, CRT, FFmpeg into bin) | `cmake/LumaForgeDeploy.cmake` | Have — release packaging + launcher added on top |

## Known defects found

| Defect | Cause | Fix phase |
|---|---|---|
| **Ctrl+Y does not redo** | `EditRedo` only has Ctrl+Shift+Z; one shortcut per action | 2/6 — multi-shortcut actions (Ctrl+Y, Ctrl+Shift+Z) + regression tests |
| `K` = Stop, `Shift+Z` = zoom fit, `=` zoom in, `Ctrl+M` export | Ad-hoc keys | 2 — spec keymap (K pause, J/L shuttle, Ctrl+=/- zoom, …) |
| Export action shows "arrives with the next milestone" | No export module | 19 — real export |
| Backspace does not delete | Single shortcut | 2 |
| Timeline has no vertical scroll; tracks fixed | Lanes laid out from y=ruler | 3 |
| No way to add/remove tracks | `SequenceEdit` cannot add tracks | 3 |
| Logs/settings next to the exe, caches only in RAM | Development defaults | 1/15 — data root + cache manager |
